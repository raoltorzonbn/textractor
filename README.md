## Overview

Textractor hooks into running Windows processes to extract in-game text, pipe it to machine-translation services, and overlay translated text, making untranslated visual novels and JRPGs playable.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Textractor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Process Hooker** | Attach to any running process and enumerate text output hooks |
| **Translation Pipe** | Route extracted text to DeepL, Google Translate, or local LLMs |
| **Overlay Display** | Floating overlay shows translations synchronized to text advancement |
| **Extension API** | C++ and JavaScript extension interface for custom post-processing |
